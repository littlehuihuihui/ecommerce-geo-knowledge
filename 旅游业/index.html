门票门票与客流指标（5 项）

入园人次

口径

闸机核销汇总；需与退票、年卡多次入园口径对齐。

平均票价（ASP）

口径

含联票分摊时按财务分摊规则折算单票等价收入。

票券核销率

口径

周期与票种维度需与售票数据严格对齐。

提前购票占比

口径

常取 T-3、T-7 等阈值，按业务统一约定。

动态定价执行偏差

口径

分票种、分渠道对比建议价带与实际成交分布。

酒店酒店与住宿指标（4 项）

RevPAR

口径

与 STR 对标时注意免费房、自用房是否剔除。

入住率（OCC）

口径

Out-of-order 房是否计入可售需统一。

平均房价（ADR）

口径

含服务费、早餐打包时按政策是否计入房费。

收益捕获率（Yield）

口径

理想房价可取竞品上限或历史峰值分位。

渠道渠道分析指标（3 项）

渠道销售占比

口径

建议同时看订单量占比与收入占比（含佣金前/后）。

直订占比

口径

需排除旅行社代客在官方下单的重复计算规则。

渠道边际贡献

口径

增量测算建议配合对照组或 MMM/归因模型。

用户用户分析指标（4 项）

新客占比

口径

以统一 ID（会员/设备/证件）定义“新”。

复购率

口径

滚动窗口（如 12 个月）比自然月更平滑。

RFM 价值分层占比

口径

阈值可按分位数或业务规则季度滚动更新。

NPS / 满意度

口径

问卷与行为代理指标（投诉、差评）可加权合成。

模型分析模型与方法（6 类）

竞品对标模型

输入 / 输出

公开数据、调研、暗访 → 雷达/差距矩阵与行动项。

价格弹性模型

输入 / 输出

历史价量面板、促销活动 → 弹性系数与最优价格带。

客流预测模型

输入 / 输出

历史客流、日历、事件 → 点预测与置信区间。

渠道归因模型

输入 / 输出

点击流、订单路径、曝光日志 → 渠道贡献度与 ROI。

用户分群模型

输入 / 输出

交易、行为、画像特征 → 分群标签与运营策略映射。

收益最大化模型

输入 / 输出

需求分布、竞品价、约束集合 → 最优控制策略表。
