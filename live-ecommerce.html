⭐ 北极星指标

North Star Metric
UV 价值
GMV ÷ 观看UV

直播电商的核心效率指标，衡量每个观众贡献的销售额，是"人货场"三者匹配度的综合体现。UV 价值越高，流量变现效率越好。

为什么是 UV 价值？

只看观看人数不看转化是空有流量，只看GMV不看流量效率是烧钱换规模。UV价值综合反映了主播能力、选品质量和流量精准度，是直播复盘的核心指标。

4大框架

人货场模型

从主播（人）、商品（货）、场景（场）三个维度分析直播表现，找到优化方向。

人：主播能力 + 流量质量
货：选品 + 价格 + 供应链
场：直播间 + 场景 + 氛围
📋

直播复盘体系

系统化的直播后复盘流程，从数据到问题到优化，形成完整的PDCA闭环。

数据复盘 → 流量复盘 → 转化复盘
商品复盘 → 主播复盘 → 问题诊断
🔻

流量漏斗分析

从曝光到支付的全链路漏斗，定位流失最大环节，针对性优化。

曝光 → 进入 → 停留 → 点击 → 下单 → 支付
💰

GMV 拆解模型

将GMV拆解为可运营的子指标，找到增长杠杆，制定针对性策略。

GMV = 观看UV × 转化率 × 客单价
