月销量

月销量 = Σ(零售上险 + 批售交付 − 合理冲回规则)

统计月内完成销售并计入销量的车辆数量，可按零售/批售口径分别披露

月产量

月产量 = Σ(各工厂/产线月度下线合格整车数量)

统计周期内主机厂完成生产并计为产量的车辆台数或折算标准车当量

市占率

市占率 = 品牌(或细分)销量 / 市场总销量 × 100%

在可比市场边界内，某主体销量占总体销量的比例

订单转化率

订单转化率 = 已锁单且完成交付数 / 有效大定或小订池 × 100%

从订单意向到实际成交的转化效率，口径需统一退订与改配规则

增换购占比

增换购占比 = 增购或换购用户销量 / 总销量 × 100%

再次购车或置换购车用户在总销量中的结构占比

出口占比

出口占比 = 海关口径出口销量(或金额) / 企业总销量 × 100%

外销车辆在总产销中的占比，可结合目的地市场拆分

护栏指标

质量与体验

产能利用率

产能利用率 = 实际产量 / 设计产能 × 100%

在既定统计周期内，实际产出相对产线或工厂设计产能的利用程度

单车毛利率

单车毛利率 = (整车销售收入 − 整车销售成本) / 整车销售收入 × 100%

分摊到单台车的毛利水平，可区分布局车型与区域

续航里程

CLTC/WLTP 等标准工况下台架与路试认证里程

在法规或企业宣称工况下，满电可行驶里程，需区分标称与实测

能量密度

质量能量密度 Wh/kg = 额定容量(Ah)×标称电压(V) / 电池包质量(kg)

单位质量电池所储存的电能，分为电芯级与系统级

风控 / 质量指标

边界与健康

充电倍率

C-rate = 充电电流(A) / 额定容量(Ah)

相对额定容量的充电快慢能力，常见 1C、2C、4C 等表述

循环寿命

达到容量保持率阈值(如80%)时的等效满充放循环次数

在指定温度与充放电深度策略下，电池容量衰减至约定水平前的循环能力

电池成本

电池包$/kWh 或 元/Wh = 材料+制造+良率摊销+物流等全成本

单位储能容量的综合成本，可拆电芯与 PACK 级

自燃率

自燃率 = 行业或品牌确认热失控起火事件数 / 保有量 × 10^n 车·年

在一定保有量与时间窗口内热失控导致起火的统计频率

车桩比

车桩比 = 新能源汽车保有量 / 公共+私人充电桩数量

衡量充电设施相对车辆规模的覆盖水平

时间利用率

时间利用率 = 桩实际充电小时数 / 统计窗口可用小时数 × 100%

单桩或场站在时间维度上的忙碌程度

功率利用率

功率利用率 = ∫实际输出功率 dt / (额定功率×统计时长)

设备额定功率在时间上的利用程度

快充桩占比

快充桩占比 = 功率≥阈值的桩数量 / 总桩数量 × 100%

高功率直流桩在总量中的结构

设备在线率

设备在线率 = 可运营状态时长 / 统计总时长 × 100%

桩端或平台侧上报的可用、可计费状态占比

单桩日均服务车次

单桩日均服务车次 = 日充电会话数 / 运营桩数

平均每根桩每天服务的车辆次数

产能利用率
实际产量 / 设计产能 × 100%

制造阶段盯产能利用与产量，看工厂是否吃满。

应用场景排产与产能规划期。

电池技术与性能

  • 能量密度 - 单位质量电池所储存的电能，分为电芯级与系统级（含结构件与热管理）。
  • 续航里程 - 在法规或企业宣称工况下，满电可行驶里程，需区分标称与实测。
  • 充电倍率 - 相对额定容量的充电快慢能力，常见 1C、2C、4C 等表述。
  • 循环寿命 - 在指定温度与充放电深度策略下，电池容量衰减至约定水平前的循环能力。
  • 电池成本 - 单位储能容量的综合成本，可拆电芯与 PACK 级。
🔄

充电基础设施

  • 车桩比 - 衡量充电设施相对车辆规模的覆盖水平，需区分公桩/私桩口径。
  • 时间利用率 - 单桩或场站在时间维度上的忙碌程度。
  • 功率利用率 - 设备额定功率在时间上的利用程度，反映“快充能力是否被吃满”。
  • 快充桩占比 - 高功率直流桩在总量中的结构，阈值可按政策或企业定义(如≥60kW、≥120kW)。
  • 设备在线率 - 桩端或平台侧上报的可用、可计费状态占比，剔除计划检修。
