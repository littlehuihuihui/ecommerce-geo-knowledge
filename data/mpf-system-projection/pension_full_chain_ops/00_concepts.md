# 养老金全链路业务 · 概念说明书

> 目的：用香港强积金（MPF）把「四角色全流程」讲清楚，并能精准解读各类业务诉求。  
> 对照岗位要求：熟悉养老金全链路业务流程，涵盖**受托人、雇主、参保人以及平台**全流程。  
> 金额与时点以公开制度/积金局表述为准；本页为学习笔记，**不能当合规意见书**。

---

## 1. 四角色是谁（一张表）

| 角色 | 英文常用 | 在链路里干什么 | 典型「对方想问你什么」 |
|------|----------|----------------|------------------------|
| **雇主** | Employer | 开业登记计划、为雇员登记、扣款汇款、处理离职与遣散相关义务 | 「我有没有违规？月底前要交多少？取消对冲后怎么改流程？」 |
| **参保人 / 成员** | Scheme member | 被登记入计划、选基金、自愿供款、转职合并、达龄/提前领取 | 「我账户有多少？换工作会丢吗？65 岁一笔过还是买年金？」 |
| **受托人** | Approved trustee | 管理注册计划、处理登记/供款/转移/提取、披露与投资安排（经基金经理） | 「供款到账慢在哪？TER 能不能降？全自由行后客户会不会走？」 |
| **平台** | eMPF / 积金易 | 行政流程数字化与标准化；集中提交、查询、部分转移与费用结构 | 「平台费降了净回报怎么变？碎片账户能不能合并？接口/时效 KPI？」 |

旁路角色（本模块点到为止）：**积金局 MPFA**（监管）、**基金经理**（投资执行）、**社署**（综援/长津等第一支柱，见 `three_pillar_adequacy`）。

## 2. 全链路六阶段（业务顺序，不是模型层）

```
① 准入登记 → ② 供款汇缴 → ③ 投资积累 → ④ 转职/转移 → ⑤ 提取/产品化 → ⑥ 合规与服务
     雇主·成员·受托·平台贯穿每一段；监管在旁监督
```

| 阶段 | 主责角色 | 关键动作（教学口径） | 接现有模型 |
|------|----------|----------------------|------------|
| ① 准入登记 | 雇主 → 受托人 / 平台 | 新雇主开业后限期登记计划；新雇员限期登记；自雇人士自行登记 | 对象一「覆盖率」旋钮；百科「参与率 / 雇主登记合规率」 |
| ② 供款汇缴 | 雇主（+雇员扣款）→ 受托人 / 平台 | 有关入息 × 各 5%（上下限）；按期足额；拖欠进入执法 | 对象一 \(C^{\mathrm{ER}}+C^{\mathrm{EE}}+C^{\mathrm{SE}}\)；入息上下限 |
| ③ 投资积累 | 成员选基金；受托人安排 | DIS / 成分基金；费用侵蚀净回报 | 对象一净回报；对象三职业生涯滚存 |
| ④ 转职 / 转移 | 成员 + 受托人 + 平台 | 保留账户、合并、雇员自选（全自由行分阶段） | **制度总资产不变**；改变账户分布与受托人竞争（对象一有意边界） |
| ⑤ 提取 / 产品化 | 成员（+年金公司） | 65 岁提取；永久离港等提前理由；一笔过为主，可部分年金化 | 对象一 \(W_t\)；对象三耗尽；对象四年金；三层替代率 |
| ⑥ 合规与服务 | 四角色 + 监管 | 投诉、时效、TER、稽查案件 | 百科「受托人运营质量」北极星；非对象一资产方程 |

## 3. 「业务诉求」怎么解读（面试可用口诀）

收到一条诉求时，按四步翻译：

1. **谁说的？** → 四角色之一（或监管/政策）  
2. **卡在哪一阶段？** → ①～⑥  
3. **要的是合规、钱、体验，还是政策影响？**  
4. **落到哪张表/哪个模型旋钮？** → 对象一～四 / 三层替代率 / 百科指标  

反例：把「全自由行」直接改对象一总资产——**错**（总池不变，变的是受托人间分布）。  
正例：把「eMPF 降费」接到净回报敏感性——**对**（见设计构想文档 eMPF 0.37%→0.29% 量级）。

## 4. 和「对象一～四 + 三层替代率」的咬合图

```
雇主合规·登记·汇款 ──► 对象一 供款层 C
成员选基·供款年数 ──► 对象三 个人账户 A(t)
平台降费·TER      ──► 对象一/三 净回报 r_net
成员达龄/离港提取 ──► 对象一 W ；对象三 耗尽年龄
提取后买年金      ──► 对象四 终身地板
提取策略 + 福利    ──► three_pillar 初期/地板替代率
积累不足落综援    ──► 对象二 财政加总
受托人竞争·转移   ──► 【业务层必讲｜资产方程有意不建】
```

## 5. 制度与金额锚点（真实来源 vs 边界）

| 项目 | 教学取值 / 表述 | 来源口径 | 边界 |
|------|-----------------|----------|------|
| 强制供款费率 | 雇主、雇员通常各 **5%**（有关入息） | 《强制性公积金计划条例》制度规则 | 自雇一般为己方 5%，无「双 5%」 |
| 有关入息上下限 | 现行量级约月入 **7,100–30,000** 港元 | 积金局公开检讨 / 模型数据字典 | 模型内 **2028 起上限 4 万** 为 `[假设]`，尚未当立法事实 |
| 新雇主登记 | 开业后约 **60 天内**须登记 | 百科 `pension.html` / 公开合规常识口径 | 以积金局最新指引为准 |
| 取消对冲 | **2025-05-01** 起，雇主强制性供款权益不得再对冲转制后服务年资的遣散费/长服金 | 劳工处 / 政府宪报口径（对象一设计文档） | **不具追溯力**；转制前服务仍可能 hybrid |
| eMPF 平台费 | 约 **0.37% → 0.29%**（积金局公布，自 **2026-04-01** 起） | 对象一 / `12_model_design_concept` | 影响**净**回报；非毛回报 |
| 制度总资产起点 | 约 **16,700 亿**港元（2026 年中量级） | 积金局统计摘要量级 | 研究投影锚点，非实时行情 |
| 退休提取形态 | 一笔过约占九成五（教学口径） | 对象一面试材料 | 行为随产品与教育可变 |
| 全自由行 | 首阶段约 **2025-09 修例、预计 2026 Q4 实施**；次阶段约 2027 立法 | 对象一综合仪表盘说明 | **不改变制度总资产** |
| 三层替代率目标带 | 约 **40%–70%**（世界银行常用建议带） | 百科 methodology / `00_concepts`（三支柱） | 港人实际依赖强积金+福利结构不同 |

未列入上表的运营 SLA（如「查询必须 N 日回复」）一律标 **`[教学简化]`**，面试时主动说「以受托人服务承诺与积金局披露为准」。
