强积金制度总账户 · 精算预测模型

模型设计构想文档（Design Concept）

性质：设计逻辑说明书——只讲「为什么这么建、层与层怎么咬合、变量从哪来、风险在哪」。 不包含：代码实现、预测结果表、虚构时间序列。 时间口径：投影期 2026–2056，年度步进。 对象口径：制度总账户（系统级存量—流量），非单个成员账户精算。 定位：面试展示与后续业务扩展的共同骨架；非积金局官方精算。

1. 核心设计理念：为什么这么做

1.1 一句话定位

本模型要回答的不是「明年股市涨跌」，而是：

在香港强积金（完全积累制 / DC）规则下，制度总资产池 \(A_{t+1}=A_t(1+r_t)+C_t-W_t\) 在未来三十年如何演化，以及人口结构、条例断点、投资回报各自把路径往哪推。

1.2 为什么必须先做人口模型

强积金是完全积累制：没有现收现付式的代际转移公式，资金池完全由流入（供款）与流出（提取）决定。两端都被人口结构锚定：

端 人口锚定点 若跳过人口层会怎样
流入 供款主体是约 18–64 岁在职人口；劳动参与率随年龄上升后下降 用「总劳动人口 × 固定增速」会抹平高龄劳动参与下跌，高估中后期供款
流出 常态提取锚定法定年龄约 65 岁；未来 10–20 年是战后婴儿潮后段进入提取窗 用「提取金额线性外推」会错过队列洪峰，拐点年份失真
结构 香港近年呈「自然减少 + 净移入部分抵消」 忽略迁移会系统性偏估劳动年龄池与永久离港漏损

因此人口层不是「装饰用背景」，而是整座模型的基石。方法上必须用队列成分法（Cohort Component Method）：按年龄×性别推进「存活 → 生育 → 迁移」，而不是对总人口做线性外推。线性外推默认年龄结构形状不变；香港老龄化下，形状本身就是主变量。

1.3 设计三条铁律

  1. 自下而上、不可倒装：没有人口，就不谈缴费人数；没有缴费与达龄队列，就不谈提取；没有流量，就不谈资产路径。
  2. 真实锚点优先、缺口标假设：总资产、供款量级、有关入息上下限、死亡率等优先锚定公开制度/统计；缺数一律标注 [假设] 并写清依据。
  3. 香港制度特有变量显式入模：上下限检讨、取消对冲、eMPF 费率、永久离港漏损——避免做成「任何国家都能套」的教科书 DC 模型。

1.4 模型要识别什么（设计目标，非本文件结果）

  • 总资产路径 \(A_t\)、年度供款 \(C_t\)、年度提取 \(W_t\)
  • 净现金流拐点：\(C_t-W_t\) 由正转负的年份（提取开始大于供款）
  • 资产峰值年份：若投影期内出现 \(A_t\) 由升转降的年份
  • 情景与敏感性：回报、入息增速、覆盖率、提取行为、条例参数变动如何改变上述拐点

2. 四层架构与依赖关系

2.1 文字架构图（自下而上）

┌─────────────────────────────────────────────────────────────┐
│  第四层  资产演化层                                          │
│  A(t+1) = A(t)×(1+r) + C(t) − W(t)                          │
│  输出：资产路径、净流出年份、资产峰值、三情景对比            │
└──────────────────────────▲──────────────────────────────────┘
                           │ 吃入：C(t)、W(t)、r、A0
┌──────────────────────────┴──────────────────────────────────┐
│  第三层  领取层                                              │
│  退休提取 ← 达65岁队列 × 提取比例 × 人均余额                 │
│  其他提取 ← 永久离港 / 提早退休 / 重疾等                     │
│  ★反馈：人均余额依赖 A(t)/账户数；W 又回改 A(t+1)            │
└──────────────────────────▲──────────────────────────────────┘
                           │ 吃入：准退休/达龄队列；吃入 A(t)
┌──────────────────────────┴──────────────────────────────────┐
│  第二层  缴费层                                              │
│  缴费人数 ← 劳动年龄人口 × LFPR × 就业率 × 覆盖率            │
│  供款额   ← 人数 × 有关入息规则（上下限）× 强制费率 + 自愿   │
└──────────────────────────▲──────────────────────────────────┘
                           │ 吃入：分年龄×性别劳动年龄人口
┌──────────────────────────┴──────────────────────────────────┐
│  第一层  人口与劳动力模型（基石）                            │
│  队列成分法：存活 × 生育 × 迁移                              │
│  输出：有效供款人口池、每年达65岁队列、老龄化路径            │
└─────────────────────────────────────────────────────────────┘

2.2 层间依赖（必须遵守的数据流）

从 → 到 传递什么 设计含义
L1 → L2 分性别、分 5 岁组（约 15–64）人口 缴费人数随年龄结构变化，不是一条总量曲线
L1 → L3 准退休队列（如 60–64）或「新达 65 岁」流量 领取洪峰由队列决定，不是由供款增速倒推
L2 → L4 年度总供款 \(C_t\)（强制 + 自愿） 流入端
L3 → L4 年度总提取 \(W_t\)（退休 + 其他） 流出端
L4 → L3 期末/期初总资产 \(A_t\)（及账户数路径） 反馈回路：余额↑ → 同人数下提取金额↑
外生 → L4 净投资回报率 \(r\)（可再扣行政费率） 情景主开关
外生 → L2 有关入息上下限、覆盖率、工资增速、自愿占比 条例与行为开关
外生 → L3 一笔过占比、其他提取占比、永久离港强度 行为与漏损开关

禁止的捷径：用「总资产历史 CAGR」直接外推到 2056——那会绕过人口洪峰与条例断点，面试时无法解释机制。

2.3 各层设计要点

第一层：人口与劳动力模型（基石）

项目 设计选择
方法 队列成分法：单岁或细年龄推进后汇总 5 岁组；分男/女
输入 基年分年龄性别人口、年龄性别死亡率、生育率（ASFR/TFR）、净迁移规模与年龄权重；劳动参与率、就业率（供 L2）
迁移 显式变量。香港近年「自然减少 + 净移入抵消」必须进模型，否则劳动年龄池与老龄化率双失真
死亡率 允许改善，但改善率宜随年龄递减（高龄改善空间更小），避免「全年龄固定 1%/年」的粗糙外推
输出 （1）有效供款人口池（劳动年龄结构）；（2）每年达到/接近 65 岁的队列；（3）老龄化率路径
情景 低/中/高主要通过生育与迁移强弱区分，便于与缴费、回报情景组合或隔离

第二层：缴费层

项目 设计选择
人数公式 \(\text{缴费人数}=\text{劳动年龄人口}\times\mathrm{LFPR}\times\text{就业率}\times\text{强积金覆盖率}\)（建议分年龄×性别后再加总）
金额公式 强制供款 ≈ 缴费人数 × 平均有关入息（经上下限截断）× 12 × 合计强制费率（雇员+雇主，通常各 5%）
上下限规则 月入低于下限：雇员可不供，雇主仍按规则缴；超过上限部分不计入有关入息
自愿性供款 独立变量，不要揉进强制费率。近年自愿性供款占总供款比重已升至约两成以上量级（以积金局年报/统计口径为准），应用占比 \(\kappa\) 或「强制×乘数」单独投影，并做敏感性
可替换接口 下限 \(Y_{\min}\)、上限 \(Y_{\max}\)、覆盖率、入息名义增速、\(\kappa\)——条例一变只改参数，不改架构

第三层：领取层

项目 设计选择
退休提取人数 当年新达 65 岁人数 × 实际提取比例（实务上接近全员提取）
提取方式 真实行为以一笔过为主（积金局披露口径下，退休提取中一笔过长期约九成以上，近年报道常见「约 94%+」量级）——基准情景可近似「达龄即全额提出账户余额」；分期领取作情景扩展，不作为默认
其他提取 永久离港、提早退休、小额结余、死亡、重疾等；设计上可按「占总提取约 10–15%」的份额参数处理，或分理由拆行——其中永久离港是香港特有漏损，宜保留独立旋钮
关键反馈回路 投资回报推高 \(A_t\) → 人均账户余额上升 → 同人数下 \(W_t\) 上升 → 反过来压低后续 \(A_{t+1}\) 的计息基数。高回报情景未必「永远更宽裕」，提取金额会被余额抬高——这是模型必须保留的非线性，不是 bug

第四层：资产演化层

项目 设计选择
核心恒等式 \(A_{t+1}=A_t\times(1+r_t)+C_t-W_t\)（费用可并入净回报，或单独 \(E_t\)）
计息惯例 先对期初存量计息，再加减当年流量（期末惯例近似）；面试时要说清，避免与「年中流量」口径混淆
拐点识别 （1）净流出年：首次 \(W_t>C_t\)；（2）资产峰值年：首次 \(A_{t+1}
三情景（回报） 保守约 3% / 基准约 4.9% / 乐观约 7%（系统加权净回报中枢；可与历史长期区间、配置权重对齐，并单独做 eMPF 费率敏感性）

3. 关键变量清单

约定：标注 真实锚点 = 有公开制度/统计可对齐；[假设] = 建模选择，须可敏感性测试；政策情景 = 已立法或检讨中、应用情景开关而非静默写死。

3.1 第一层：人口与劳动力

变量 角色 来源或假设依据
基年分年龄×性别人口 投影起点 政府统计处（C&SD）人口统计 / 年中人口（建模时对齐具体表号，如年中人口系列）
年龄×性别死亡率 存活推进 C&SD 生命表/死亡率统计；预测段用改善率外推
死亡率年化改善率 长寿风险 [假设]：经验改善 + 随年龄递减先验（高龄改善更弱），避免固定年降幅
总和生育率 / ASFR 出生流入 对齐 C&SD《人口推算》叙事与表；高/低情景做 ± 扰动
出生性别比 出生拆分 [假设] 约 1.06（男/女），可敏感性
净迁移总量及年龄权重 「自然减少+净移入」 总量对齐官方推算量级；年龄权重偏劳动年龄 [假设]
劳动参与率（分年龄性别） 供款人数 C&SD 劳动力统计；路径可设缓慢变化 [假设]
就业率 供款人数 C&SD / 劳动力统计锚点

3.2 第二层：缴费

变量 角色 来源或假设依据
雇员/雇主强制费率 通常各 5% 《强制性公积金计划条例》制度规则
有关入息下限 / 上限 现行约 \$7,100 / \$30,000（港元/月） 积金局现行指引；下限、上限分别自约 2013、2014 年起未再调（积金局公开表述）
拟议新上下限 政策情景开关 检讨中：媒体与劳顾会咨询口径多见拟升至约 \$10,500 / \$40,000；积金局称目标向政府提交建议，尚未立法生效——模型应作情景，不作基线默认
平均有关入息 / 工资名义增速 供款强度 校准至近年制度总供款量级（积金局年报/统计）；增速分情景 [假设]
强积金覆盖率 就业者中强制参与比例 [假设]，并与「缴费人数 ≤ 劳动人口×就业率」自洽
自愿性供款占比 \(\kappa\) 独立流入 积金局统计：自愿性供款近年占总供款约两成以上量级；路径 [假设]
自雇供款 强制流入子集 制度规则（通常单边 5%）；可并入强制或单列

3.3 第三层：领取

变量 角色 来源或假设依据
法定/常态提取年龄 默认约 65 岁 强积金法定提取条件（建模常取 65 为常态）
一笔过提取占比 提取形态 积金局披露的提取方式结构；公开讨论常见退休提取中一笔过约 94%+——基准可近似全额提取
新达龄人数 领取流量 由 L1 队列推出（如 60–64 组 / 5 的近似，或单岁精确）
人均账户余额 提取金额 [假设]：由 \(A_t\) / 账户数推导，并可加退休账户溢价系数；从而闭合反馈回路
账户数路径 分母 积金局账户总数锚点 + 缓慢增长 [假设]
其他提取占比 非退休流出 [假设] 约占总提取 10–15%；其中永久离港单独标注
永久离港强度 香港特有漏损 积金局「永久离开香港」提取统计；近年可降，但不可从模型删除

3.4 第四层：资产与回报

变量 角色 来源或假设依据
期初总资产 \(A_0\) 存量锚点 积金局公布的强积金总净资产量级（建模年中/年末口径须统一）
系统净回报 \(r\) 三情景 [假设] 保守 3% / 基准约 4.9% / 乐观 7%；中枢可参考长期基金类别表现与配置权重
行政费率 / eMPF 侵蚀毛回报 积金易平台费：由约 0.37% 下调至 0.29%（积金局 2026-03 公布，自 2026-04-01 起）；影响净回报假设
取消对冲 结构性断点 2025-05-01 起，雇主强制性供款累算权益不得再对冲转制后服务年资的遣散费/长服金（劳工处 / 政府宪报口径）。设计含义：雇主强制部分更完整留在成员账户 → 长期推高制度总资产、抬高未来提取基数；应用「对冲漏损衰减」参数，而非一次性加一笔整数

3.5 香港特有变量（避免教科书模型）——设计处理方式

特有变量 为何必须显式 在模型中的位置
供款上下限检讨 13 年未调；一旦上调，高收入段强制供款跳升、部分低收入雇员退出强制雇员供款 L2 参数情景（\$7,100/\$30,000 → 拟议 \$10,500/\$40,000）
取消对冲（2025-05-01） 制度性改变雇主强制供款「留存完整性」 L2/L4：降低「对冲导致的账户漏出」；抬高 \(A_t\) 与未来 \(W_t\)
eMPF 费率下降 直接改善净回报 L4：\(r_{\mathrm{net}}\) 上调 8bp 量级（0.37%→0.29%）的敏感性，或写入基准净回报
移民/永久离港漏损 DC 池的跨境退出阀 L3：其他提取中的独立项；与 L1 迁移叙事分开（迁移进人口 ≠ 离港提款）

4. 已知局限与假设风险

4.1 口径与边界局限

局限 说明 面试时怎么说
制度总账户 ≠ 成员公平精算 不模拟每个账户的归属、投资选择、转职合并 「这是系统水位模型，不是个人养老金计算器」
非官方精算 不替代积金局 / 政府精算评估 「公开数据可复现的研究框架」
年步长 + 期末计息 忽略年内缴付时点、市场路径依赖 「方向与拐点量级优先，日内精度不做」
ORSO / 职业计划抵销细节 本版可简化或不纳入 「强积金主池优先」
无完整蒙特卡洛 先用三情景 + 滑块敏感性 「二期再上随机情景」

4.2 假设风险（按影响力排序）

  1. 投资回报 \(r\)

    对三十年期末资产与提取金额（经余额反馈）最敏感。基准 4.9%、乐观 7% 都是假设中枢，不是预测承诺。

  1. 人均余额如何从总资产推导

    达龄者余额通常高于系统人均；若系数偏低，会低估领取洪峰。这是 L3↔L4 反馈里最大的结构不确定性之一。

  1. 有关入息上下限是否、何时上调

    检讨方向明确，但生效时点与最终数字未立法。基线应保留现行 \$7,100/\$30,000，拟议值做政策情景。

  1. 取消对冲的量化幅度

    方向清晰（强制雇主供款更少因对冲流出），但「每年少漏出多少」缺乏简单公开时间序列，参数不得不假设，需做上下带宽。

  1. 死亡率改善与极高龄

    改善率递减是合理先验，仍是假设；长寿主要影响人口结构与达龄队列，对 DC 总池的影响弱于 DB，但会改变领取年期叙事。

  1. 自愿性供款路径

    近年占比升至约两成以上，能否维持取决于税优惠、市场情绪与收入——不宜锁死常数。

  1. 永久离港

    波动大、政策与宏观敏感；应用情景而非点估计。

  1. 一笔过 ≈ 100% 提取

    接近现实，但若未来年金/分期产品起量，领取层形态会变，资产沉淀更久——属产品结构风险。

4.3 设计上已预留、但本构想阶段不展开的扩展

  • 将 eMPF 费率、基金开支比率与「毛回报」拆开
  • 取消对冲资助计划对雇主行为（进而对自愿供款）的二阶影响
  • 分基金类型配置漂移（DIS、股债比例）
  • 与政府财政视角对接：把 L2 换成税收、L3 换成综援/高龄津贴（人口层与存量—流量骨架可复用）

5. 小结：这套设计要让面试官听懂的三句话

  1. 强积金是 DC，水位由供款与提取决定；两端都钉在年龄结构上，所以必须先做队列成分法人口层。
  2. 四层只能自下而上：人口 → 缴费 → 领取（含余额反馈）→ 资产恒等式；香港特有的上下限、取消对冲、eMPF、离港漏损是显式旋钮，不是脚注。
  3. 模型的诚实之处在于：真实锚点对齐公开数据，其余全部标假设，并用情景与敏感性暴露最大风险在回报、余额推导和条例断点。
