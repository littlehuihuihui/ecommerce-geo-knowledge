强积金制度总账户 · 30年预测基础数据字典（2026–2056）

P0 五表交付面（推荐）：p0_foundation/（见该目录 00_data_dictionary.md） 用途：为「强积金制度总账户」系统动力学 / 精算投影提供年度颗粒度输入。 金额口径：除入息为「港元/月」或「万港元」外，系统级流量与存量统一为亿港元。 情景：低 / 中 / 高（悲观 / 基准 / 乐观）。 说明：根目录 01–05 CSV 为早期 Prompt 1-1 版本；P0 设计文档对应数据集以 p0_foundation/T01–T05 为准（默认有关入息上下限采用拟调整值 \$10,500/\$40,000）。

0. 设计原则

  1. 真实锚点优先：总资产、账户数、供款率、有关入息上下限、预期寿命等采用公开制度/统计锚点。
  2. 缺失则标注 [假设]：给出依据，并与其他表自洽（缴费人口 < 劳动人口；入息落在有关入息带内等）。
  3. 不替代官方精算：本数据集用于研究与教学建模，非 MPFA / 政府官方预测。

3. 情景定义（低 / 中 / 高）

维度 低 中 高
缴费人数增长 缓降/停滞 微增后平台 温和扩张
入息增长 ~1.2%/年 ~2.5%/年 ~3.5%/年
投资净回报 历史带下限 中枢 历史上限
老龄化 65+增长偏慢 基准 偏快
提取比例 偏高（资金更早流出） 0.35 起 偏低（更多保留）

4. 建议闭合恒等式（建模时）

期末总资产 ≈ 期初总资产 × (1 + 系统净回报)
            + 年强制性供款流入
            + 自愿供款/其他流入[本数据集未单列，可扩]
            − 系统提取流出
            − 费用与其他[可扩]

2026 中枢示意：流入约 622 亿港元（见核心参数推算）。
