要回答的问题

一个人退休后，靠政府津贴 + 强积金 + 年金，每月大概能有多少钱？相对退休前工资的比例（替代率）够不够？ 中产为何常领不到长津？买年金后会不会反而撞上入息上限？花光强积金后还剩什么「地板」？

1. 三层收入思路（世界银行口径）

把退休月收入拆成三层再相加，再除以退休前月收入：

第一支柱 政府+ 第二支柱 强积金+ 第三支柱 年金→ ÷ 退休前月薪 = 替代率
  • 第一支柱：综援 / 长者生活津贴 / 生果金（三者互斥，只能选一条路）
  • 第二支柱：强积金剩余账户按年提取（会花光）
  • 第三支柱：用一部分余额买的终身年金月付

2. 数字从哪来

  • 强积金余额、前年薪、年金月付、剩余提取：接对象三/四已跑出的代表性个体（中产基准、不同年金化比例、男女费率）
  • 长津 / 生果金月额与限额：社署公开数字（本页标注 2026-02 起长津约 $4,345；入息/资产上限见页眉）
  • 综援月额：教学量级约 $8,600（非正式资格结论）
  • 低收入 / 极低资产情景：手工设定资产与薪，用来对照「谁能领长津/综援」

3. 第一支柱怎么判定「发不发」

  1. 先选定申请哪一种（长津 / 生果金 / 综援 / 不申）
  2. 用计入入息（含年金月付）和计入资产（剩余强积金一般计入；已付年金保费通常不计入资产）做示意审查
  3. 通过 → 加上对应月额；不通过 → 记 $0，并在表里写明原因（资产超限 / 入息超限 / 年龄不够等）

这就是「中产申长津失败、50% 年金后入息仍超限」等情景的来源。

4. 为什么有两个替代率

  • 初期：刚退休，还有强积金提取 +（可能的）津贴 + 年金
  • 地板（长寿）：强积金剩余花光后，只剩津贴 + 年金 —— 看活得久时还够不够

对照带约 40%–70%（世界银行常用区间）。页面 KPI 会标是否落在建议带。

5. 本页「展示 / 计入统计」在干什么

上面算好的是各模块原始月额（情景表里已定）。本页不重跑资格，只让你自由组合：

  • 展示：概念卡、堆叠图系列、表列是否出现 —— 方便讲概念时藏掉干扰项
  • 计入统计：是否加进合计与替代率 —— 例如关掉强积金 = 只看长寿地板；只开长津+年金 = 学「津贴与年金如何叠」

长津/综援/生果金在数据里同一情景只有一列非零，勾选多个也不会双计政府津贴。

6. 和对象一～四怎么接

对象一 制度池· 对象二 综援财政加总· 对象三 个人强积金· 对象四 年金化→ 本页：个人能不能领第一支柱 + 合并替代率

对象一/二管「系统有多大」；对象三/四管「个人账户与年金」；本模块补上「个人侧第一支柱资格 + 三层合并」，方便面试讲清概念。

7. 局限（诚实边界）

  • 资格是示意规则，不是社署正式批核；家庭、租金、豁免资产等未建模
  • 中产画像来自对象三/四基准路径，不是人口抽样
  • 综援为量级示意；伤残津贴等其他公共福利金未纳入
  • 金额以社署最新公布为准；本页为学习与面试叙事工具
