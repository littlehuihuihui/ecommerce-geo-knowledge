# 强积金年金化提取模型 · 数据字典

> 对象三自然延伸：65岁余额 → 终身年金 + 剩余提取  
> **权衡：年金化解决长寿风险，但降低流动性**

## 核心公式

```
年金年收入 = 余额 × 年金化比例 × 分性别转换率
剩余余额 = 余额 × (1 − 年金化比例)
初期年收入 = 年金 + max(0, 目标支出 − 年金)（来自剩余提取）
终身地板 = 年金 + 其他收入   # 不随账户耗尽归零
```
